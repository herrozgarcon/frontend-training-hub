## 🌟 Interactive Showcase Portal

- 🏷️ **Category Filter**: Quickly isolate Web Apps, UI Clones, or Portfolios.

## 🛠️ How to Run & Preview Locally

### Option 1: VS Code Live Server (Recommended)
1. Open this repository folder in **Visual Studio Code**.
2. Right-click on root [`index.html`](./index.html) or any project's `index.html`.
3. Select **"Open with Live Server"**.

### Option 2: Python Local Server
Run this single command from the project root:
```bash
python3 -m http.server 8000
```
Then open your browser and visit: **[http://localhost:8000](http://localhost:8000)**

### Option 3: Direct Browser Launch
Simply double-click [`index.html`](./index.html) to open the interactive portal directly in your default browser.

## 🌐 Deploy to GitHub Pages (Live Online)

To make all these projects accessible via a public web link anytime:
1. Go to your repository on GitHub: `https://github.com/herrozgarcon/hcl-training`
2. Click **Settings** > **Pages** (under Code and automation).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Within 1–2 minutes, your portal will be live at:
   ```
   https://herrozgarcon.github.io/hcl-training/
   ```
